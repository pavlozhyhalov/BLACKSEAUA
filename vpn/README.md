# BLACKSEAUA VPN 🇺🇦

Власний **багатокористувацький VPN з українською IP-адресою** на базі
[WireGuard](https://www.wireguard.com/) — сучасного, швидкого й безпечного протоколу.

Дає змогу тобі та людям, яким ти роздаси доступ, «заходити в інтернет з України»:
українські банки, «Дія», ПриватБанк/monobank, українські сервіси та контент
працюватимуть так, ніби ти фізично в Україні.

> **Важливо, як це працює.** VPN — це не веб-сайт і не код у браузері. Щоб мати
> українську IP, потрібен **сервер (VPS), який фізично стоїть в Україні**. Цей
> комплект автоматизує все інше: піднімає VPN на такому сервері однією командою
> та керує користувачами. Сервер орендуєш ти (кілька доларів на місяць).

---

## Що всередині

| Файл | Призначення |
|------|-------------|
| `install.sh`  | Ставить і налаштовує VPN-сервер на чистому VPS (одна команда). |
| `wg-users.sh` | Додає/видаляє користувачів, генерує конфіги та QR-коди. |

---

## Крок 1. Оренда українського VPS

Потрібен **KVM-VPS в Україні** з Ubuntu 22.04/24.04 (не OpenVZ — там не працює VPN).
Мінімально вистачить найдешевшого тарифу (1 CPU / 1 GB RAM). Приклади провайдерів
з локаціями в Україні:

- **HostPro**, **Ukraine.com.ua**, **Delta Host**, **ThunderVPS**, **FreeHost** — українські хостери;
- **Hetzner**, **DigitalOcean** — світові, але **без локації в Україні** (не дадуть українську IP), тому для цієї задачі не підходять.

Орієнтовна ціна: **~3–6 $/міс**. Один такий сервер спокійно тягне десятки
одночасних користувачів для звичайного веб-серфінгу.

Після оренди ти отримаєш: **IP-адресу сервера**, логін `root` і пароль (або SSH-ключ).

---

## Крок 2. Встановлення VPN

Підключись до сервера по SSH:

```bash
ssh root@IP_ТВОГО_СЕРВЕРА
```

Завантаж скрипти на сервер і запусти інсталятор:

```bash
# Варіант А — скопіювати файли install.sh та wg-users.sh на сервер (scp / редактором nano),
#             потім:
sudo bash install.sh
```

Скрипт сам:
- встановить WireGuard;
- згенерує ключі сервера;
- увімкне маршрутизацію та NAT;
- запустить VPN і додасть його в автозапуск.

Наприкінці побачиш `Endpoint` — це адреса, до якої підключаються клієнти.

> **Не забудь** у панелі провайдера / фаєрволі відкрити **UDP-порт 51820**
> (або той, що вкажеш). Якщо провайдер ріже нестандартні порти — запусти інсталятор
> з `WG_PORT=443`:
> ```bash
> sudo WG_PORT=443 bash install.sh
> ```

## Крок 3. Додавання користувачів

Для кожної людини (і для себе) створи окремий профіль:

```bash
sudo ./wg-users.sh add ivan
```

Скрипт покаже **QR-код** просто в терміналі та збереже файл
`/etc/wireguard/clients/ivan.conf`.

- **Телефон:** встанови застосунок **WireGuard** ([iOS](https://apps.apple.com/app/wireguard/id1441195209) / [Android](https://play.google.com/store/apps/details?id=com.wireguard.android)) → «+» → «Сканувати QR-код» → готово.
- **Компʼютер:** встанови [WireGuard для Windows/macOS/Linux](https://www.wireguard.com/install/), передай людині файл `ivan.conf` і зроби «Import tunnel from file».

Увімкнув перемикач у застосунку — і ти вже в українському інтернеті. Перевірити
IP можна на [ipinfo.io](https://ipinfo.io) — має показати Україну.

---

## Керування

```bash
sudo ./wg-users.sh list          # хто є + активні підключення
sudo ./wg-users.sh add   olena   # додати
sudo ./wg-users.sh del   ivan    # видалити (доступ одразу зникає)
sudo ./wg-users.sh qr    olena   # знову показати QR
sudo ./wg-users.sh show  olena   # показати текст конфіга
```

Зміни застосовуються **на льоту**, без розриву чужих зʼєднань.

## Налаштування (необовʼязково)

Перед запуском `install.sh` можна перевизначити змінні:

| Змінна | Дефолт | Опис |
|--------|--------|------|
| `WG_PORT` | `51820` | UDP-порт (постав `443`, якщо блокують). |
| `WG_DNS` | `1.1.1.1,1.0.0.1` | DNS для клієнтів. |
| `WG_NET` | `10.66.66.0/24` | Внутрішня підмережа VPN. |
| `WG_ENDPOINT` | автовизначення | Публічна IP/домен сервера, якщо автовизначення хибне. |

Приклад:
```bash
sudo WG_PORT=443 WG_DNS="9.9.9.9" bash install.sh
```

## Часті проблеми

- **«Немає /dev/net/tun»** — у тебе OpenVZ-VPS. Візьми KVM або увімкни TUN у панелі.
- **Підключення є, але інтернету нема** — не відкритий UDP-порт у фаєрволі провайдера,
  або сервіс не запущено: `sudo systemctl status wg-quick@wg0`.
- **IP показує не Україну** — сервер орендований не в українській локації.
- **Логи/діагностика:** `sudo wg show`, `sudo journalctl -u wg-quick@wg0 -e`.

## Безпека та відповідальність

- Роздавай доступ **тільки людям, яким довіряєш** — весь їхній трафік іде через твій сервер.
- Файли `*.conf` і QR-коди містять приватні ключі — не викладай їх публічно.
- Використовуй сервіс законно: він призначений для приватності та доступу до
  українських сервісів, а не для протиправних дій. Відповідальність за використання
  несе власник сервера.
